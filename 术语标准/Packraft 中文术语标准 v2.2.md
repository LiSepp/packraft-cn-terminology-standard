# Packraft 中文术语标准 v2.2

> 发布日期：2026-08-10
> 适用范围：Packraft（背包船）教材、正文、图注、索引、术语表及 XHTML 校订
> 执行状态：v2.2 为当前正式版本，替代 v2.1 作为后续翻译与校订标准

## 一、适用范围与使用原则

1. 本标准以 Packraft（背包船）的船体结构、使用方式和安全场景为基准，不直接套用硬壳皮划艇的整套术语体系。
2. 白水、水文、急流救援、绳索、医学和海上导航中的通用专业概念，采用相应领域中含义明确的译法。
3. 每个英文词头原则上只设一个标准译法。确有正式全称、正文短称或不同语境译法时，必须在“说明”栏写明使用条件。
4. Boof、T-boning、Munter hitch、Magic X、Voile、Tenacious Tape 等动作名、结名、系统名或品牌名，可保留英文；首次出现时补充中文说明。
5. 安全术语必须明确动作主体、动作结果和风险对象。不得为了追求字面对称而使用可能误导操作的译法。
6. 产品说明与本标准不一致时，先确认该词是否为品牌自定义部件名；通用术语仍按本标准执行，品牌专名按官方拼写保留。
7. 原文明指 Packraft 时优先译为“背包船”，不以“艇”“船艇”等泛称替代；原文泛指多种船只或救援平台时，按语境译为“船只”“救援船”等，不强行窄化为背包船。

### 4. 白水、水文与河道特征

| English | 标准译法 | 说明 |
|---|---|---|
| Current | 水流 | 泛指具有方向和速度的水体运动。 |
| Flow | 水流 | 表示流动状态；表示数量时按语境译为“流量”。 |
| Whitewater | 白水 | 因落差、障碍和水流掺气形成的湍急水流环境。 |
| Flatwater | 静水 | 指无明显急流、浪花或白水特征的平缓水域；作定语时统一写“静水划行”“静水背包船”“静水横渡”。 |
| Hydrology | 水文学 | 指研究水体分布、运动和变化的学科；作定语或指资料、现象时按语境用“水文”。 |
| River character | 河流总体特征 | 指一条河流或河段在流量、坡度、河床、障碍和连续性等方面的综合表现。 |
| River feature | 河道特征 | 包括河道地形和水流特征，不限于地貌。 |
| Substrate | 河床底质 | 河床表层的岩石、砾石、沙或其他材料。 |
| Morphology | 河道形态 | 指河道平面、纵剖面和横断面等形态。 |
| Bedrock | 基岩 | 河床或岸壁的完整岩体。 |
| Sediment | 沉积物 | 被水流搬运或沉积的颗粒物。 |
| Alluvium | 冲积物 | 由河流搬运并沉积形成的松散物质。 |
| Gradient | 河段比降 | 河段高程差与相应河段长度之比；原文若只指总高程差，不译为比降。 |
| Discharge | 流量 | 单位时间通过断面的水体体积。 |
| Stage | 水位 | 相对于规定基准面的水面高程。 |
| Gauge | 水位计 | 测量或记录水位的仪器；原文明指 staff gauge 或 gauge board 时才译为“水尺”。 |

| Meanders | 曲流河段 | 河道连续弯曲的形态。 |
| Cutbank | 凹岸 | 曲流外侧受侵蚀形成的陡岸。 |
| Point bar | 凸岸边滩 | 曲流内侧因沉积形成的边滩；地貌专业文献亦见“点坝”。 |
| Constriction | 河道收窄 | 河宽突然或逐渐变窄的河段。 |
| Undercut | 掏蚀岸壁 | 水下或水线附近被水流向内掏空的岩壁或岸壁。 |
| Log jam | 木材堵塞 | 倒木、树干和枝条在河道内聚集形成的堵塞障碍。 |
| Strainer | 滤水障碍物 | 水能穿过而人体或背包船可能被截留的障碍，常由倒木、枝条或围栏构成；须与 sieve 区分。 |

| Trailing wakes | 尾迹波 | 背包船或其他物体运动后在其后方形成的扰动波列；若强调整个扰动区，可写“尾流”。 |
| Hole | 水洞 | 水流越过障碍后形成、表层向上游回卷的白水流态；首次可写“水洞（hole）”，并非河床坑穴或洞穴。 |
| Keeper | 滞留型水洞 | 回卷作用足以持续滞留背包船或落水者的危险水洞。 |
| Backwash | 回卷流 | 水洞内表层向上游回卷的水流。 |
| Boil | 上涌流 | 水从深处向表面翻涌形成的流态。 |
| Boil line | 翻涌分界线 | 回卷水在下游重新上涌并与外流交界的可见边界，常标示水洞或低水头坝回流水区的外缘。 |
| Tongue | 舌状水流 | 平滑、通常指向下游并呈舌形的水流。 |
| Sieve | 岩隙通水结构 | 水可穿过河床岩石或障碍间隙，而人体和背包船难以通过的危险结构；须与 strainer 区分。 |
| Pillow | 枕浪 | 水流撞击岩石或障碍后在其上游侧隆起形成的压力浪。 |
| Eddy | 回水区 | 障碍后方或岸边形成、流向与主流不同的局部回流区；不等同于水文学中由壅水形成的回水河段。 |
| Eddy line | 回水线 | 主流与回水区之间的边界。 |
| Eddy fence | 回水栅状流 | 回水边界上连续竖起、形似栅栏的扰动水流。 |
| Seam | 水流接缝 | 两股速度或方向不同的水流交界线；确为两股水流汇合时，可在说明中写“汇流线”。 |
| Shear zone | 剪切区 | 相邻水流速度或方向差异较大的区域。 |
| Big water | 大流量白水 | 以大流量、强推压和大型浪体为主要特征的白水。 |
| Creeking | 陡溪划行 | 以陡峭、通常流量较小且技术性强的溪流为对象的背包船下行，不与溪降运动混用。 |
| Horizon line | 水面断线 | 因前方跌水、堰坎或陡降使下游水面从视野中消失的警示特征。 |
| Aeration | 水流掺气 | 空气掺入水流并形成气泡的过程或状态。 |
| Green water | 低掺气水 | 白水语境中指未破碎、含气较少的“实水”，不是按水色命名；首次可写“低掺气水（green water）”。 |
| Laminar flow | 层流 | 流体分层规则、横向混合较少的流动；严格判断依据流动条件，不能只看水面是否平滑。 |
| Turbulent flow | 紊流 | 具有明显脉动、旋涡和混合的流动。 |
| Drop | 跌水 | 河床高程突然下降形成的落差。 |
| Merging channels | 汊道汇合处 | 两条或多条水道重新汇合的位置或河段。 |
| Helical current | 螺旋流 | 沿主流方向同时发生旋转的三维水流。 |
| Cork-screw current | 螺旋流 | 对 helical current 的形象说法，不另造“开瓶器式”技术名；正文应按原文说明旋转方向和影响。 |
| Flash flood | 骤发洪水 | 水位和流量在短时间内迅速上涨的洪水；明确发生在山地小流域时可按语境译为“山洪”。 |
| Pushiness | 水流推压感 | 白水划行中的定性感受，指水流持续推迫背包船、限制路线选择并压缩反应时间。 |
| Recovery zone | 恢复区 | 急流或关键动作下游相对缓和、可供重新登船、救援或集结的区域；安全性随水位和下游危险而变，并非绝对安全区。 |
| Conveyor belt | 传送带式水流 | 对速度集中、方向较稳定并持续输送背包船或落水者之流带的形象说法，不作为固定水文学分类。 |

| Safety net | 安全保障 | 降低失误后果的备用人员、装备、撤离方案或救援条件。 |
| Trip plan | 行程计划 | 包括路线、时间、水位、天气、队伍、通信和撤离方案。 |
| In-town contact | 留守联系人 | 不随队出行、掌握行程并能在逾期时启动响应的人。 |
| Difficulty rating | 难度评级 | 对河段或动作技术难度的分级。 |
| River rating | 河流难度评级 | 对具体河段综合难度的分级。 |
| Class I | I 级 | 国际河流难度分级中的 I 级。 |
| Class II | II 级 | 国际河流难度分级中的 II 级。 |
| Class III | III 级 | 国际河流难度分级中的 III 级。 |
| Class IV | IV 级 | 国际河流难度分级中的 IV 级。 |
| Class V | V 级 | 国际河流难度分级中的 V 级。 |
| Class VI | VI 级 | 国际河流难度分级中的 VI 级。 |

## 三、易混术语与禁用译法

| English | 本版标准 | 禁用或避免译法 | 原因 |
|---|---|---|---|
| Spray deck | 防浪甲板 | 防水裙 | 与穿戴式 spray skirt 不是同一部件。 |
| Spray skirt | 防浪裙 | 防水裙与 spray deck 合并 | 必须与船体甲板结构分开建项。 |
| Cockpit | 座舱 | 驾驶舱 | Packraft 中不是车辆或航空器驾驶舱。 |
| Thwart | 横向座囊 | 横梁、横座板 | Packraft 语境通常指横向座体或充气结构。 |
| Perimeter line | 船体周边绳 | 艇周绳、周长绳 | “船体周边绳”对象和位置更清楚；“周长”是数学量。 |
| Read-and-run | 即视即划 | 边读边划 | Read 指观察和判读河流，不是阅读文字。 |
| Power on / Power off | 主动发力 / 停止发力 | 动力开 / 动力关 | 不是设备电源开关。 |
| Drysuit | 干衣 | 干式潜水服 | 本书指划桨与水上活动用干式防寒服。 |
| PFD | 救生衣 | 个人漂浮装置 | 本书统一采用读者熟悉的“救生衣”；仅在直接引用法规、标准或产品正式名称时保留原名称。 |
| TPU | TPU | 热塑性聚氨酯 | 本书统一保留材料缩写 TPU；仅在直接引用标准、化学名称或解释材料成分时按原文处理。 |
| Wet exit | 水中离船 | 湿脱、水中离艇 | 必须明确脱离背包船的动作，并避免无必要的“艇”字泛称。 |
| Wet re-entry | 水中重新登船 | 湿式重入、水中回艇 | 必须明确重新登上背包船的对象和结果。 |
| Ferrule | 桨杆接头 | 桨连接管 | 该词指连接或锁定机构，不一定是管件。 |
| Feather angle | 桨叶错位角 | 羽角 | “羽角”不能清楚表达两桨叶相对偏转。 |
| Heuristics | 启发式判断 | 启发式偏差 | 启发式本身不等于认知偏差。 |
| Packraft roll | 背包船滚翻复位 | 背包船翻滚 | 必须体现恢复正位的动作结果。 |
| Combat roll | 急流中滚翻复位 | 实战翻滚 | 不是对抗动作。 |
| Creeking | 陡溪划行 | 溪降 | 避免与 canyoning 溪降运动混淆。 |
| Horizon line | 水面断线 | 地平线 | 指前方落差造成的水面视线中断。 |
| Aeration | 水流掺气 | 水体含气、充气水 | “掺气”能同时表达过程与状态，不是人工充气饮料。 |
| Point positive | 指向安全方向 | 指向正向 | “正向”没有明确参照物。 |
| Belayed swimming | 绳索保护游进 | 制动保护游泳 | 核心是绳索保护，不是给游泳“制动”。 |
| Mechanical advantage | 机械倍力 | 机械增益 | 救援绳索语境应体现倍力作用。 |
| Progress capture | 进度捕捉 | 进程捕获 | 绳索技术资料中使用“进度捕捉”；说明中必须明确其防回滑功能。 |
| Self-equalizing anchor | 自动均力锚系统 | 自平衡锚点 | Equalizing 指载荷均分，不是姿态平衡。 |
| Z-pull | Z 形倍力拖拽系统 | Z 形拖拉系统 | 旧译遗漏倍力功能。 |
| Fetch | 风程 | 风区 | 核心通常是风连续吹过水面的有效距离。 |
| Slack water | 憩流 | 平潮水 | 指时段或流动状态，不是一种水。 |
| Range markers | 导标 | 定位标志物 | 通常为成对对准、指示航向的导航设施。 |
| IERCC | 国际应急响应协调中心 | IRCC、国际救援协调中心 | 仅用于对应历史资料中的正式全称；当前机构名为 Garmin Response。 |
| Flush drowning | 急流冲刷型溺水 | 无明确诱因溺水 | 旧译遗漏连续急流冲刷这一核心语境。 |
| Outfitting | 背包船适配 | 与 Rigging 合并为装配 | 两者对象和功能不同；本书明确对象为背包船。 |
| Rigging | 装载与系固 | 与 Outfitting 合并为固定系统 | 应突出装备装载、连接和固定。 |
| Clean rigging | 无缠挂隐患的系固 | 清爽固定 | 这是安全要求，不是外观描述。 |
| Flow | 水流 | 心流 | 本书相关章节指水体运动。 |
| Green water | 低掺气水 | 非含气水、仅写绿水且不解释 | 通常仍含少量空气；该词强调未破碎、含气较少，不是颜色。 |
| Hull speed | 船体临界航速 | 船体最高速度 | 不是绝对不可超过的最高速度。 |
| Gauge / River gauge | 水位计 / 水文测站 | 水位尺 / 河流水位测站无条件混用 | 前者是水位测量仪器，后者是监测水文要素的测站；staff gauge 才译“水尺”。 |
| Strainer / Sieve | 滤水障碍物 / 岩隙通水结构 | 二者都译为滤障或筛障 | Strainer 常由倒木、枝条等构成；sieve 通常是河床岩石或障碍间隙。 |
| Hole | 水洞 | 回旋流坑、水坑 | 白水运动已有“水洞”用法；它是回卷流态而非河床坑穴，首次应保留英文解释。 |
| Pool-drop | 跌水—深潭交替型河段 | 潭—跌式河段 | 该河型的功能顺序是急流或跌水之后进入恢复深潭。 |
| Flash flood | 骤发洪水 | 无条件译为山洪暴发 | Flash flood 不限于山区；只有明确山地小流域语境时才用“山洪”。 |
| Recovery position | 恢复体位 | 复苏体位 | 该体位用于维持气道通畅，不等同于心肺复苏动作。 |
| Flood / Ebb | 涨潮流 / 落潮流 | 仅按水位上涨 / 下降定义 | 潮流按水平方向判断，相关时刻不一定与潮位阶段严格同步。 |

## 四、维护规则

1. 新增术语前先检查是否已存在单复数、动词形式或同义词条，避免重复建项。
2. 英文斜线合并项仅用于真正同义词。不同部件、不同动作或不同机构必须拆分建项。
3. 标准译法栏不并列两个无条件同义译法。短称、图注用法和语境变体写入说明栏。
4. 安全、医学、绳索和维修步骤中的数字、单位、比例及警告必须逐项对照英文原文，不得由术语表自行补造。
5. 品牌名、产品名、机构名和人名等应保留官方拼写，并在首次出现时给出中文功能说明。
6. 地名采用中国大陆通行译名并补足行政区划或地理类型，如 Alaska 译为“阿拉斯加州”、Colorado River 译为“科罗拉多河”；人名保持原文拼写。
7. 面向中国读者的译文统一使用公制：磅换算为千克或克，英寸换算为厘米或毫米，英尺和码换算为米，英里换算为千米，华氏度换算为摄氏度，立方英尺每秒换算为立方米每秒。数值按使用场景保留合理有效位数，并用“约”标明近似值。
8. 货币金额原则上保留原币；确需换算时，另附按翻译或出版当日权威汇率计算的约值并标明日期。术语标准不固定汇率，也不把换算金额作为实时价格或购买建议。
9. 河流左右岸统一以面向下游为基准；观察者左右侧统一以观察者当前朝向为基准。
10. 术语表只规定词义和使用口径，不能替代专业培训、产品说明书或现场风险判断。
