# Packraft 中文术语标准 v2.0（2606）

本文档是一份 packraft 中文术语推荐标准，用于中文写作、翻译、课程材料、活动说明、装备介绍和社群交流。它不是强制行业标准，而是一个便于长期协作的统一用语基准。

## 1. 标准目标

Packraft 在中文语境中长期存在“橡皮艇”“漂流艇”“背包艇”“便携艇”等混用问题。这些说法各有合理来源，但容易造成三类误解：

- 把 packraft 误解为普通充气玩具艇或商业漂流艇。
- 忽略它“可携行、可徒步接驳、可在多地形线路中使用”的核心特征。
- 在安全、教学和装备沟通中造成不必要歧义。

本标准的目标是：

- 建立稳定、自然、可传播的中文主译名。
- 保留必要英文关键词，便于跨语言检索和购买装备。
- 区分装备、活动、技术、风险和线路场景。
- 让新手能看懂，让专业玩家也不觉得别扭。

## 2. 总体译名原则

### 2.1 packraft 的推荐译名

推荐译名：**轻量探险艇**

首次出现建议写作：

> 轻量探险艇（packraft）

选择“轻量探险艇”的理由：

- “轻量”体现可背负、可携行的核心属性。
- “探险”覆盖徒步、骑行、河流、湖泊、峡谷和多地形线路。
- “艇”比“船”更符合小型个人水上装备的中文习惯。
- 该译名避免把 packraft 简化成“橡皮艇”或“漂流艇”。

### 2.2 可接受别称

| 中文别称 | 建议使用场景 | 备注 |
| --- | --- | --- |
| Packraft | 装备型号、国际品牌、双语资料 | 中文文档首次出现后可直接使用。 |
| 背包艇 | 入门科普、口语交流 | 简洁，但容易弱化水域技术属性。 |
| 便携探险艇 | 装备介绍 | 比“背包艇”正式，但不如“轻量探险艇”稳定。 |

### 2.3 不推荐译法

| 不推荐译法 | 问题 |
| --- | --- |
| 橡皮艇 | 范围过宽，容易联想到普通娱乐充气艇。 |
| 漂流艇 | 容易限定在商业漂流或激流场景，不能覆盖静水和远征线路。 |
| 皮划艇 | 与 kayak、canoe 混淆。 |
| 充气艇 | 只描述结构，不体现携行和线路特征。 |
| 筏艇 | 生硬，不利于大众传播。 |

## 4. 写作规范

### 4.1 首次出现

中文文章或活动说明中，首次出现建议使用：

> 轻量探险艇（packraft）

后文可根据读者对象选择“轻量探险艇”或“packraft”。如果面向搜索、装备购买或国际资料引用，建议在标题或摘要中保留 packraft。

### 4.2 标题用语

推荐：

- 轻量探险艇入门指南
- Packraft 静水基础课程
- 激流轻量探险艇安全清单
- 某某河轻量探险艇线路记录

不推荐：

- 橡皮艇漂流全攻略
- 皮划艇 packraft 教程
- 充气船探险标准

### 4.3 安全语境

涉及安全时，术语应优先准确而不是口语化：

- 用“个人漂浮装备（PFD）”，不要只写“救生衣”。
- 用“翻艇自救”，不要只写“落水爬回去”。
- 用“筛滤障碍”“横扫障碍”，不要只写“树枝”。
- 用“水位窗口”，不要只写“水大/水小”。

### 4.4 装备语境

装备规格中可保留英文缩写和品牌惯用词：

- TPU
- PFD
- ISS
- T-Zip
- Cargo Fly
- spray deck
- self-bailer

建议格式：

> 该艇配备艇内储物系统（ISS / Cargo Fly）和防浪裙舱面（spray deck）。

推荐按以下层级理解 packraft 相关中文：

## 6. 示例句

推荐写法：

- 本线路适合有静水经验的轻量探险艇玩家。
- 第三段存在筛滤障碍，建议提前上岸勘察并视情况绕行搬运。
- 首次下水请穿戴个人漂浮装备（PFD）和头盔。
- 这是一条水陆组合线路，轻量探险艇的优势在于可以随徒步装备一起携行。
- 当前水位超过推荐窗口，不建议新手下水。

不推荐写法：

- 这条河适合橡皮艇随便漂。
- 有救生衣就没问题。
- 水大一点更刺激。
- 这个 packraft 和普通皮划艇差不多。

## 8. 后续维护方向

后续版本可继续补充：

- 激流等级中文说明。

- 教学课程常用口令。
- 装备规格表的中英对照字段。
- 安全事故复盘中的标准表述。
