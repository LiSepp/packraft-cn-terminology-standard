# 背包船中文术语与译本

> 本项目由李结果（果果）负责维护。
>
> 内容包括背包船中文术语标准、沉浸式翻译术语库，以及背包船与河流水文中文译本。

本项目面向 Packraft / Packrafting（背包船及背包船活动）语境，旨在提供一致、可检索且便于实际使用的中文术语与译本资料。部分水文术语翻译参考 GB/T 50095—2014《水文基本术语和符号标准》（*Standard for essential terminology and symbol in hydrology*）；该参考仅用于部分水文术语的中文表达，不替代标准原文、专业培训或现场安全判断。

## 推荐基础译法

| English | 推荐中文 | 说明 |
| --- | --- | --- |
| packraft | 背包船 | 正式中文名称；首次出现可写“背包船（Packraft）”。 |
| packrafting | 背包船活动 | 指以背包船进行的划行、旅行或综合户外活动。 |
| packrafter | 背包船划手 | 泛指参与者时可写“背包船活动参与者”。 |
| whitewater | 白水 | 指因落差、障碍和水流掺气形成的湍急水流环境。 |
| flatwater | 静水 | 指湖泊、水库及水流平缓的河段。 |
| PFD | 救生衣 | 首次出现建议写“救生衣（PFD）”。 |
| drysuit | 干衣 | 不译为“干式潜水服”。 |

完整术语、适用语境和禁用译法以 v2.2 标准文件为准。

## 使用与安全

品牌名、产品名、机构名、绳结名及必要动作名保留官方英文拼写，并在首次出现时补充中文说明。技术动作、安全、救援、装备参数和警告信息应逐项核对原始资料；术语表和译本不能替代专业培训、产品说明书或现场风险判断。
