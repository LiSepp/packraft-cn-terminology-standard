# Packraft 中文术语标准

Packraft 中文术语标准 v2.1 是一份面向中文语境的术语规范，用于统一背包船相关内容中的船体结构、装备、划行技术、白水环境、安全救援、维修、医学、导航和风险管理表达。

## 当前版本

- 标准文件：[Packraft 中文术语标准 v2.1](docs/packraft-cn-terminology-standard-v2.1.md)
- 发布日期：2026-07-10
- 版本定位：中文写作、翻译、教学、活动说明、装备资料和 XHTML 校订的推荐用语
- 维护原则：以背包船语境为准，表述清楚、便于检索、避免误导安全操作，并保留必要英文关键词

v2.1 已替代 v2.0，旧版文件不再作为执行标准。

## 推荐基础译法

| English | 推荐中文 | 说明 |
| --- | --- | --- |
| packraft | 背包船 | 正式中文名称；首次出现可写“背包船（Packraft）”。 |
| packrafting | 背包船活动 | 指以背包船进行的划行、旅行或综合户外活动。 |
| packrafter | 背包船划手 | 指操控背包船的人员；泛指参与者时可写“背包船活动参与者”。 |
| whitewater | 白水 | 指因落差、障碍和水体含气形成的湍急水流环境。 |
| flatwater | 静水 | 指湖泊、水库及水流平缓的河段。 |
| PFD | 个人漂浮装置 | 首次出现建议写“个人漂浮装置（PFD）”；具体产品为救生衣时可写“救生衣（PFD）”。 |
| drysuit | 干衣 | 指划桨和水上活动用干式防寒服，不译为“干式潜水服”。 |

不建议将 packraft 固定译为“轻量探险艇”“橡皮艇”或“漂流艇”：前者不是行业通行品类名，后两者会混淆船型、材料和使用场景。

## 使用建议

1. 正文首次出现核心词时，可采用“中文标准译法（English）”；后文统一使用中文标准译法。
2. 面向安全、教学和活动组织时，优先使用能明确动作主体、操作结果和危险对象的术语。
3. 品牌名、产品名、机构名、绳结名及必要动作名保留官方英文拼写，并在首次出现时补充中文说明。
4. 数字、单位、安全警告和操作步骤必须逐项对照英文原文，不能由术语表自行补造。
5. 完整术语、适用语境和禁用译法以 v2.1 标准文件为准。

## 维护约定

新增或修订术语时，请同时确认：

- 英文原词及具体语境
- 唯一的标准中文译法
- 必要的短称或语境变体
- 禁用或应避免的旧译
- 使用说明、安全限制或例句

不同部件、动作或机构不得仅用斜线合并为一个词条。确需双译时，必须写明各自的适用条件。
