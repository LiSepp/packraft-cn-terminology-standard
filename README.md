# Packraft 中文术语标准

Packraft 中文术语标准 v2.0（2606）是一份面向中文语境的术语推荐稿，用于统一 packraft 相关内容中的器材、技术、环境、风险和行程表达。

## 当前版本

- 标准文件：[Packraft 中文术语标准 v2.0（2606）](docs/packraft-cn-terminology-standard-v2.0-2606.md)
- 版本定位：中文写作、翻译、教学、活动说明和装备资料的推荐用语
- 维护原则：清晰、可检索、不过度音译、保留必要英文关键词

## 推荐基础译法

| English | 推荐中文 | 说明 |
| --- | --- | --- |
| packraft | 轻量探险艇 | 作为正式中文名；首次出现可写作“轻量探险艇（packraft）”。 |
| packrafting | 轻量探险艇活动 | 指运动、旅行或综合活动。 |
| packrafter | 轻量探险艇玩家 | 面向大众语境；正式场景可用“参与者”。 |
| whitewater | 激流 | 用于水域类型和技术难度。 |
| flatwater | 静水 | 指湖泊、水库、平缓河段等。 |
| PFD | 个人漂浮装备 | 首次出现建议写作“个人漂浮装备（PFD）”。 |

## 使用建议

1. 面向大众传播时，优先使用推荐中文，并在首次出现处保留英文关键词。
2. 面向安全、教学和活动组织时，优先选择不含歧义的术语，例如“个人漂浮装备”“翻艇自救”“水位窗口”。
3. 面向装备规格时，可保留国际通用缩写，例如 TPU、PFD、ISS、T-Zip。
4. 不建议把 packraft 直接固定译为“橡皮艇”或“漂流艇”，这会混淆品类、材料和使用场景。
