# 沉浸式翻译 Packraft AI 术语库

本目录提供可导入沉浸式翻译“AI 术语库”的 Packraft 英中术语文件，适用于背包船相关网页、教材和技术资料的 AI 翻译。

## 文件说明

- [packraft_glossary.csv](packraft_glossary.csv)：含 336 条术语，列结构为 `source,target,tgt_lng`，目标语言统一为 `zh-CN`。
- 术语来源：[Packraft 中文术语标准 v2.2](<../术语标准/Packraft 中文术语标准 v2.2.md>)中的“标准术语库”。
- 原标准中 `Paddle` 和 `Swim` 各有两种明确的语境译法，CSV 按原文保留；AI 翻译时应结合上下文选择。

## 导入与使用

1. 打开沉浸式翻译设置中的“AI 术语库”。
2. 通过“导入/导出”功能导入 `packraft_glossary.csv`。
3. 启用该术语库，并使用支持 AI 术语库的 AI 翻译服务。

AI 术语库用于提高专业词汇的一致性，不适用于 Google、Microsoft 等普通机器翻译服务。具体入口和名称可能随沉浸式翻译版本变化，请以当前界面为准。

## 参考说明

此翻译适用于packraft背包船运动，部分术语翻译参考GBT 50095 2014 水文基本术语和符号标准。术语库不收录该标准全文，也不能替代专业训练、产品说明书或现场风险判断。
